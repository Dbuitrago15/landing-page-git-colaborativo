# landing-page-git-colaborativo

Actividad de Computación en la Nube: trabajo colaborativo con ramas de Git e integración en `main`.

**Sitio publicado:** https://dbuitrago15.github.io/landing-page-git-colaborativo/

| Rol | Rama | Archivo |
|---|---|---|
| Estudiante 1 – Estructurador | `rama-html` | `index.html` |
| Estudiante 2 – Diseñador | `rama-css` | `style.css` |
| Estudiante 3 – Interactor | `rama-js` | `app.js` |
| Estudiante 4 – Administrador | `main` | Merge de las 3 ramas, `<link>` + `<script>` en `index.html` y GitHub Pages |

> Actividad desarrollada de forma individual: una misma persona asumió los 4 roles.
